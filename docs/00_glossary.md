# 名词解释

按在流水线里出现的顺序排。遇到不懂的词先来这里查。

## 仿真与机器人

- **Isaac Sim**：NVIDIA 的机器人仿真器，底层物理引擎是 PhysX。特点是能在 GPU 上同时跑几千个机器人副本。
- **IsaacLab**：架在 Isaac Sim 上的 RL 框架。你在里面定义"环境"：机器人、观测、奖励、重置规则。论文的 200 Hz 仿真 / 50 Hz 控制就是在这一层配。
- **Unitree G1**：宇树的人形机器人，论文用的是 29 自由度版本。
- **PD 目标（PD targets）**：策略输出的不是力矩，而是每个关节的目标角度；仿真器里的 PD 控制器再把角度差转成力矩。
- **本体感知（proprioception）**：机器人自己能感知到的状态：躯干朝向、线速度、角速度、关节角度和角速度。不包括对外界的观测。
- **特权状态（privileged state）**：仿真里能拿到、真机上拿不到的信息（比如物体精确位姿）。论文只给 critic 用，不给 actor 用。

## 数据

- **SMPL-X**：一种参数化人体模型，用几十个参数描述身体形状和姿态。TRUMANS 和 OMOMO 的人体动作都是这个格式。
- **重定向（retargeting）**：把人体动作转换成机器人动作。人和 G1 的骨架、比例不一样，所以不能直接拿来用。论文用 GMR 处理走路，用 OmniRetargeting 处理有接触的动作。
- **HSI / HOI**：human-scene interaction / human-object interaction。前者是人在场景里活动（TRUMANS），后者是人操作物体（OMOMO）。
- **高度图（heightmap）**：以机器人为中心、朝向对齐的一个 16×16 网格，每格记录地面或障碍物的高度。这是论文表示"场景"的方式。
- **BPS（Basis Point Set）**：把物体几何编码成固定长度向量的方法：预先固定一组基点，记录每个基点到物体表面的最近距离。论文用 512 维。

## Stage I

- **动作模仿 / 动作跟踪（motion imitation / tracking）**：训练一个策略让仿真里的机器人尽量贴着参考动作走。奖励就是"离参考有多近"。
- **PPO**：Proximal Policy Optimization，目前最常用的 RL 算法。三个阶段里用 RL 的地方都是它。
- **GAE**：计算优势函数的一种方法，λ 是它的平滑系数。
- **参考状态初始化（RSI）**：每个 episode 从参考动作的随机一帧开始，而不是总从头开始。
- **运动学提前终止**：机器人偏离参考动作太远就提前结束 episode，省得浪费算力。
- **RBF 核**：奖励用 exp(-e²/σ²) 的形式，e 是误差，σ 是带宽。σ 越小对误差越敏感。

## Stage II

- **VQ-VAE**：把连续向量"量化"到一个有限集合（codebook）里最近的那个。结果是每个时刻的动作被表示成一个整数 token（0 到 1023）。
- **codebook**：那 1024 个 64 维向量的集合。EMA 更新意味着不是靠梯度、而是靠滑动平均来更新它们。
- **承诺损失（commitment loss）**：让编码器输出别离它被分配到的 codebook 向量太远。β = 0.25。
- **直通估计（straight-through）**：量化这一步不可导，前向用量化后的值，反向把梯度直接传给编码器。
- **行为克隆（BC）**：用监督学习模仿教师的动作。这里是让解码器输出的动作分布对教师动作的似然最大。
- **先验（prior）**：一个 Transformer，输入本体历史和上下文，输出"下一个技能 token"的概率分布。
- **模态 mask**：训练时随机把某些上下文（比如高度图）置空，这样先验学会在信息不全时也能工作。

## Stage III

- **后训练（post-training）**：在预训练的先验基础上，用 RL 针对具体任务微调。
- **KL 正则**：让任务策略的 token 分布别离先验太远，防止 RL 学出奇怪动作。
- **CFG（classifier-free guidance）**：从扩散模型借来的技巧。先验分别在"无条件"和"只给某个模态"下各算一次 logits，再按 l_uncond + w·(l_m - l_uncond) 组合。w > 1 会放大条件的影响。论文 w = 1.5。
- **采样温度**：推理时从 token 分布采样的随机程度。0.05 几乎等于取最大值。

## 规划（你们的扩展）

- **MPPI**：Model Predictive Path Integral。采样很多条未来动作序列，用代价函数打分，按 exp(-cost/λ) 加权平均。每一帧重新算。
- **CEM**：Cross-Entropy Method。也是采样式规划，但每轮只保留分数最高的一批样本，用它们更新采样分布。
- 两者的共同点：**不需要梯度，代价函数随时可以改**。这就是"推理时换性格"的来源。
