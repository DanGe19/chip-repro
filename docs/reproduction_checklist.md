## 3. 各阶段验收标准

### 重定向
- [ ] 随机抽 10 条重定向后的 G1 动作，在 IsaacLab 里纯运动学回放（不开物理），肉眼看没有穿模、脚不打滑、搬物体时手在物体附近。

### Stage I
- [ ] 走路专家：跟踪奖励稳定上升，回放时能走完整条参考序列不摔。
- [ ] 场景专家：在 TRUMANS 场景里回放不穿墙。
- [ ] 物体专家：物体能跟着参考轨迹走（object_rel_pos 奖励项不为零且在涨）。

### Stage II
- [ ] VQ-VAE：codebook 利用率高（不是只用了几十个 token）。记录 perplexity。
- [ ] 用教师 token 序列喂解码器，重放出的动作和教师动作接近。
- [ ] 先验：在验证集上预测教师 token 的 top-1 准确率，和 mask 掉不同模态后的准确率对比。
- [ ] **论文表 3 第一行**：只用先验、不做 RL，导航 48.9%、搬运 55.2%、组合 4.8%。这是 Stage II 的一个对照点。

## 4. 评测协议（4.1）

- 随机采样初始状态和目标，所有训练用的场景和物体实例。
- 留出测试：10 个未见场景，每个场景-任务对 100 个 episode。
- 指标定义：
  - Succ：导航是机器人躯干到目标 xy 距离 < 0.15 m；搬运是物体中心到目标 xy 距离 < 0.15 m；组合要两个都成功。
  - Dist：最终的 xy 距离。
  - Coll：非足部 link 接触场景力 > 1 N 的帧占比。
  - Fail：躯干高度 < 0.2 m 算摔倒，摔倒 episode 的占比。
- **不确定**：哪 10 个场景留出、评测的 episode 数（主表）没写。
